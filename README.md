# Portfólio — Ronielli

Portfólio pessoal em React + Vite + TypeScript, com i18n (PT/EN) e tema escuro ciano/esmeralda.

## Desenvolvimento

```bash
pnpm install
pnpm dev
```

## Build

```bash
pnpm build
pnpm preview
```

## Deploy

Conecte o repositório à Vercel. O comando de build é `pnpm build` e a pasta de saída é `dist`.
